# Similarity Judgment Task

This is the repo for Similarity Judgment Task. Across 7 Experiments, we manipulated FeatureMatch between subjects, a factor with four levels (ValenceMatchingOnly, TruthCondMatchingOnly, MaxMatch, MaxMismatch). Between-subjects, we manipulated four TruthConditional Features, keeping lexical category consistent within each experiment. Thus, experiments 1a-1c tested concrete vs. abstract in verbs, adjectives, and nouns; Experiments 2a and 2b tested physical vs. psychological (verbs)/social (adjectives); Experiment 3 tested animacy in nouns; finally Experiment 4 tested syntactic categorization in nouns vs. verbs.

## Experimental Files

All experimental code is found in the directory "experiments".

## Corpus 

All corpus-based analysis, including stimuli (word pair) generation and vector similarity calculations are found here. These scripts are juptyer notebooks.
